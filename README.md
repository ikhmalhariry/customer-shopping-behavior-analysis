# customer-shopping-behavior-analysis
Customer shopping behavior: Explanatory Data Analysis and Statistical Insights

<dbl> is a "Double" which is a Continuous numeric variables, decimals, and standard numbers.
<chr> is a "Character" which is a Text, categories, labels, and names.

| Variable               | Type        | What it represents           |
| ---------------------- | ----------- | ---------------------------- |
| Customer ID            | Numeric     | Customer identifier          |
| Age                    | Numeric     | Customer age                 |
| Gender                 | Categorical | Customer gender              |
| Item Purchased         | Categorical | Purchased item               |
| Category               | Categorical | Product category             |
| Purchase Amount (USD)  | Numeric     | Purchase amount              |
| Location               | Categorical | Customer location            |
| Size                   | Categorical | Product size                 |
| Color                  | Categorical | Product color                |
| Season                 | Categorical | Shopping season              |
| Review Rating          | Numeric     | Customer review              |
| Subscription Status    | Categorical | Subscription status          |
| Shipping Type          | Categorical | Shipping method              |
| Discount Applied       | Categorical | Whether discount was applied |
| Promo Code Used        | Categorical | Whether promo code was used  |
| Previous Purchases     | Numeric     | Number of previous purchases |
| Payment Method         | Categorical | Payment method               |
| Frequency of Purchases | Categorical | Purchase frequency           |
